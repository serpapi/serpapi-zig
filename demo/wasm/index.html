serpapi-zig — browser wasm demo

Search query building and JSON parsing run as WebAssembly, compiled from demo/wasm/serpapi_wasm.zig. The actual HTTP request to SerpApi.com is made server-side by demo/wasm/serve.zig — see the note below for why.

Wasm running in a browser has no socket or TLS access, so it cannot open an HTTPS connection to serpapi.com itself — that is a browser sandboxing rule, not a Zig limitation. This page's fetch() instead calls a same-origin /api/search endpoint, served by zig build serve, which forwards the request using the regular serpapi.Client from this repository. That also keeps the secret SERPAPI_KEY on the server, never exposed to the browser — the way a real API-key-backed integration should be built, wasm or not.
